## 二、功能模块

### 2.1 时间轴 (Timeline)

**功能**：在聊天对话页面左侧显示时间标签和圆点标记，标识每一轮对话的位置。

**用户操作**：
- **导航**：点击时间轴圆点跳转到对应对话；按 `↑` / `↓` 键在对话间切换
- **预览**：鼠标悬停圆点显示对话摘要
- **长按标记**：长按圆点约500ms → 添加📌标记 → 再次长按取消
- **切换视图**：点击时间轴上方按钮 → 在圆点视图和文本列表视图之间切换
- **勾选合并**：文本列表视图下勾选多行 → 点击「合并输入(N)」→ 创建文件夹 → 将问题保存为收藏项 → 后续可通过文件夹按钮炼化模板
- **显隐控制**：可对各平台独立开关时间轴显示
- **结构提问**：时间轴右侧六边形按钮 → 分析对话结构 → 生成分类提纲

### 2.3 代码运行器 (Runner)

**触发**：AI回复中包含代码块时，右上角出现 `[Run]` 按钮。

**操作流程**：
1. 点击 `[Run]` → 代码在输出面板中执行/预览
2. 可编辑代码后点击重跑
3. 支持 7 种语言：JavaScript / TypeScript / SQL / HTML / JSON / Markdown / Mermaid

---

### 2.4 侧边栏收藏 (Starred)

**触发**：时间轴文本列表每行 ☆ 图标；对话中对话可收藏。

**操作流程**：
- **收藏**：点击 ☆ → 弹出文件夹选择 → 保存到文件夹
- **取消收藏**：点击已收藏的 ★ → 移除
- **文件夹管理**：侧边栏或面板「收藏」Tab → 新建/重命名/删除文件夹 → 支持多级嵌套
- **拖拽分类**：拖拽收藏项到目标文件夹
- **搜索**：顶部搜索框过滤收藏内容
- **展开/折叠**：点击文件夹左侧箭头 → 展开或收起

---

### 2.5 智能输入框 (Smart Input Box)

**功能**：
- **Enter 换行**：在输入框中按 Enter 仅换行，不发送（可开关）
- **双击 Enter 发送**：快速双击 Enter 键发送消息（可开关）
- **提示词按钮**：输入框左侧出现 ⚡ 按钮 → 点击下拉选择预设提示词 → 自动填入输入框（各平台可独立开关）

---

### 2.6 文件夹按钮与浮窗 ★新增

**触发**：提示词按钮下方自动出现 📁 文件夹按钮（与提示词按钮跟随同一策略定位）。

**操作流程**：

#### 打开浮窗
点击 📁 按钮 → 弹出居中大型浮窗（540×560px），内容：
- 顶部工具栏：新建文件夹 / 搜索框 / 多选模式 / **全部收起**
- 文件夹树形列表（与侧边栏收藏完全一致）
- 每个文件夹行右侧有「炼化模板」按钮

#### 新建文件夹
点击 ⊕新建文件夹 → 输入名称 → 确认

#### 搜索文件夹
在搜索框输入关键字 → 实时过滤文件夹和收藏项

#### 全部收起
点击「全部收起」按钮 → 所有展开的文件夹（包括默认的「全部问题」文件夹）折叠

#### 多选模式
点击「选择」按钮进入多选 → 勾选收藏项 → 批量移动/复制/取消收藏

#### 炼化模板（核心AI流程）
```
点击文件夹行的【炼化模板】
  → 收集该文件夹（含子文件夹）所有问题的完整内容
  → 关闭浮窗
  → 自动将结构化分析prompt填入AI输入框
  → 自动发送（600ms延迟确保输入就绪）
  → 等待AI回复（轮询检测，最长180秒）
    完成条件: 包含"完整Skill提示词"标记 且 >500字
        或 连续3次稳定 且 >500字
  → 解析AI回复并分层保存:
     · 完整AI原始回复 → 保存为提示词(source: refined_ai)
     · 「完整Skill提示词」段 → 单独保存(source: refined_skill)
     · 「层层深入提问模板」段 → 每条一行(source: refined_template)
  → Toast提示: "XX 炼化完成，已保存 N 条提示词"
```

### 2.7 高亮标注 (Highlight)

**操作流程**：
1. 选中AI回复中的文字 → 浮出工具栏 → 点击 [🖌️标注]
2. 选中的文字被高亮包裹（颜色和样式可在面板设置）
3. 重新选区覆盖已高亮文本 → 再点标注 → 删除原高亮（切换效果）
4. 刷新页面后高亮自动恢复

---

### 2.8 公式功能 (Formula)

**操作**：
- **复制公式**：悬停AI回复中的数学公式 → 点击 📋 图标 → 复制LaTeX源码到剪贴板
- **全屏查看**：AI回复中的Mermaid图表 → 点击 ⛶ 图标 → 全屏查看

---

### 2.9 快速提问 (Quick Ask)

**操作流程**：
1. 在AI回复中选中文字 → 浮出工具栏 → 点击 [💬追问]
2. 选中的文字自动以引用格式（每行加 `> `）追加到输入框末尾
3. 光标定位到末尾，用户可补充后发送

---

### 2.10 滚动到底部 (Scroll To Bottom)

**触发**：向上滚动离开对话底部时。

**操作**：输入框上方出现 `↓` 按钮 → 点击回到最新对话 → 按钮自动隐藏

---

### 2.11 聊天宽度管理 (Chat Width Manager)

**操作**：面板「聊天宽度」Tab → 拖动滑块 → 聊天区域宽度实时变化（100%~150%，只能调大不能调小）

---

### 2.12 电子宠物 (Animation)

**触发**：AI正在回复时。

**操作**：面板「电子宠物」Tab选择宠物 → AI回复时输入框上方播放动画 → AI停止后宠物隐藏

**可选宠物**：Snail(蜗牛) | Zombie(僵尸) | Ant(蚂蚁) | Wizard(巫师)

---

### 2.13 镜像站浮窗 (Mirror Site)

**触发**：在非支持的网页上（如自定义镜像站）。

**操作**：
- 右下角出现 ⭕ 浮窗按钮（可拖拽移动）
- 点击浮窗 → 弹出全平台提示词列表
- 点击任意提示词 → 复制到剪贴板（按钮闪绿反馈）
- 「管理」按钮 → 打开提示词设置
- 面板「镜像站」Tab → 添加自定义域名

---

### 2.14 闪记 (Notepad)

**触发**：时间轴区域 📝 图标。

**操作**：
- 点击打开右下角浮窗 → 自由书写笔记
- 输入停止500ms后自动保存
- 支持多笔记管理（最多50条）
- 可拖拽移动 / 8个方向调整浮窗大小

---

### 2.15 数据同步 (Data Sync)

**云同步**：上传/下载备份到 Google Drive

**手动导入导出**：
- 导出：打包所有数据 → 下载 `timeline_backup_日期.json`
- 导入：选择文件 → 选择合并模式（保留现有+新增）或覆盖模式（替换全部）

---

### 2.16 结构化提问思路提炼 (Structured Questions)

**触发**：时间轴右侧六边形按钮。

**操作流程**：
1. 点击按钮 → 选择对话范围（从哪个对话开始提取）
2. 点击「提取并分析」
3. 系统按启发式规则自动分类为三类：
   - **整体框架询问**：了解需求/范围的问题
   - **关键术语解析**：询问定义/概念的问题
   - **深入发散探讨**：追问/扩展/挑战的问题
4. 生成结构化提纲 → 可选「保存为学习模板」

> 注：纯本地规则分类，不调用AI，与炼化功能互补。

## 三、炼化模板入口汇总

| 入口 | 位置 | 触发方式 |
|------|------|---------|
| Prompt Tab | 面板 → 提示词 Tab | 选择文件夹 → 点击「炼化模板」 |
| 文件夹浮窗 ★ | 输入框旁 📁 按钮 → 浮窗 | 点击文件夹行的「炼化模板」 |
| 问题列表 | 时间轴文本列表 | 勾选问题 → 合并输入 → 创建文件夹 → 再通过文件夹按钮炼化 |

三种入口最终都走向相同的炼化流程：收集问题 → 构建prompt → 自动发送 → 等待回复 → 解析保存。

## 四、按钮交互流程汇总

### 4.1 输入框按钮
```
提示词按钮 (⚡)
  → 点击 → 下拉列表(搜索/筛选)
    → 点击提示词 → 填入输入框
    → 右键提示词 → 编辑/删除
  → 各平台可独立开关

文件夹按钮 (📁) — 位于提示词按钮下方4px
  → 点击 → 大型浮窗(540×560px)
    ├─ 新建文件夹 → 输入名称 → 确认
    ├─ 搜索 → 实时过滤
    ├─ 全部收起 → 折叠所有文件夹
    ├─ 选择(多选) → 批量移动/复制/取消收藏
    └─ 炼化模板 → 收集问题 → 自动发送 → 等待回复 → 分层保存
```

### 4.2 时间轴按钮
```
时间轴圆点
  → 点击 → 跳转到对话位置
  → 长按(~500ms) → 标记📌 / 取消标记
  → 悬停 → 显示Tooltip预览
  → ↑/↓ 键 → 上下导航

视图切换按钮
  → 圆点视图 ⇄ 文本列表视图

文本列表 - 每行
  → 点击行 → 跳转对话
  → 悬停 → 显示复选框/收藏☆/标记📌
  → 勾选多行 → 「合并输入(N)」→ 创建文件夹

结构化提问按钮(六边形)
  → 选择对话范围 → 提取分析 → 生成分类提纲 → 可选保存

闪记按钮(📝)
  → 打开浮窗 → 自由书写 → 自动保存 → 拖拽移动/调整大小
```

### 4.3 对话区域按钮
```
代码块 [Run] 按钮
  → 点击执行 → 输出面板展开 → 可编辑重跑

选中文字浮动工具栏
  ├─ [💬追问] → 引用文字 → 追加到输入框
  └─ [🖌️标注] → 高亮文字 → 持久化保存

Mermaid图表 ⛶ 按钮
  → 全屏查看

公式 📋 按钮
  → 复制LaTeX到剪贴板

滚动↓ 按钮
  → 点击 → 滚回最新对话 → 自动隐藏
```

### 4.4 侧边栏/浮窗
```
收藏☆
  → 点击 → 选择/创建文件夹 → 保存

文件夹管理
  → 右键文件夹 → 新建子文件夹/重命名/删除
  → 拖拽收藏项到文件夹 → 分类
  → 拖拽收藏项排序

镜像站浮窗 ⭕
  → 非支持页面右下角出现
  → 点击 → 提示词列表 → 点击复制到剪贴板
  → 可拖拽移动位置
```
